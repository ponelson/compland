Where Qumulo plays, and against whom

One data plane for unstructured data — across on‑prem, cloud, sovereign, and edge.

The portfolio anchors on a single scale-out file system with multi-protocol access (NFS, SMB, S3), extends globally through a cloud data fabric, and is now layering an AI-native data refinery on top. Below: the stack, the horizontal product line, and ten competitors — with the case both ways.

What it does differently

Three product principles.

01 — Meaning bound to bytes
Tags, summaries, transcripts, entities, embeddings written as extended attributes on the file. Not a sidecar database that rots when copied or moved.
02 — Continuous, not one-shot
Whisper v2→v3, Llama-3→4 — The Refinery re-runs as models improve, so the semantic layer refreshes automatically rather than going stale.
03 — Provenance on every operation
Model, version, confidence, classification, user lineage — logged per enrichment. Foundation for the eligibility-at-access control plane (federal, M&E, life sciences).

Portfolio · Editions, Cloud, & TAM Expansion

FLAGSHIP
ANQ Enterprise
$50/TB/mo · 35% uplift over base

On-prem / hybrid edition. All-features bundle plus premium support. The classic Qumulo appliance + software footprint at enterprise tier.

CLOUD
CNQ Enterprise
$36/TB/mo · 50% uplift over base

Cloud-Native Qumulo on AWS, Azure, OCI. Hyperscaler-economics file system that re-uses object storage underneath. +134% YoY ARR.

ARCHIVE
ANQ / CNQ-Frozen
Archive tier

Monetizes dark / archival data at low cost-per-TB while keeping it in the same namespace. TAM-expansion play into colder data sets.

OBJECT
Object Accelerator
S3 · ADLS Gen2 · GCS

Tiers cold data into native cloud object stores while keeping it addressable through Qumulo's file namespace. Consistent across cloud providers.

MOBILITY
Cloud Bridge
On-prem ⇄ Cloud

Bridges existing on-prem clusters to CNQ in the cloud — answer to "new nodes cost 200%+ more" customer pressure. Migration without forklift.

AI
GPU Hunting
Multi-region · Multi-cloud

Multi-region cloud GPU optimization — moves the data namespace toward wherever the next GPU pool opens up (Azure US-East, OCI US-East, etc.).

AI
Cloud AI Accelerator
Stateless · Scalable

Stateless, scalable cloud instance that connects Qumulo data to AI compute on demand. Bridges training/inference workloads to the namespace.

DR
NeuralSync
Zero RPO / RTO claim

Cross-site replication with strong consistency, positioned for DR and active-active distributed scenarios spanning continents.

PLATFORM
ARM & DPU
Power/cost optimization

ARM CPU and DPU node support — drops compute power per PB while maintaining throughput; expands TAM in dense, power-constrained DCs.

ANALYTICS
Databricks / Snowflake
